# MVP Engenharia de Dados

Projeto de demonstração de um fluxo de engenharia de dados usando plataforma do Databricks.


## Como usar

1. Clone este repositório, podendo ser direto no ambiente do Databriks com integração do Github.
2. Conforme documento MVP_Engenharia_de_Dados.ipynb ou MVP_Engenharia_de_Dados.pdf, estão descritos os processos realizados dentro da plataforma, desde a coleta, transformação e análise dos dados.
3. Scripts que foram executados estão descritos no documento e se encontram nesse repositório possibilitando reprodutibilidade.
